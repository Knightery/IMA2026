## Theme Structure

# Section dividers are bold, minimal, and easy to scan

Subsections should use one statement, one support line, and no extra decoration.

---

# Recommendation slides should read like decisions, not topics

<div class="kpi-grid">
  <div class="card">
    <h3>Primary recommendation</h3>
    <div class="metric success">5-city pilot</div>
    <p>Lead with the answer, then support it with three proof points.</p>
  </div>
  <div class="card">
    <h3>Case framing</h3>
    <div class="metric">20,000 units</div>
    <p>Use one large number or insight per card instead of dense paragraphs.</p>
  </div>
  <div class="card">
    <h3>Decision tone</h3>
    <div class="metric compare">High confidence</div>
    <p>Keep color meaning fixed across all 40 slides so judges learn it once.</p>
  </div>
</div>

> Green signals recommendation and stable performance. Rust is reserved for downside risk and stress scenarios. Gold highlights only the most important callout on the slide.
